# About

**Work in progress.** Detta är ett experiment vi bygger tillsammans i Discord med SuperGrok 4.6. Inte en färdig produkt. Inte opinion. Inte röstmaskin.

## Byggt

- Spec — actions vs words, L1 vinner
- Schema + 8 partier + topic AI
- Motor — validate, score, detect
- Riksdagen-adapter — motioner med `dok_id`
- Statisk sajt på Vercel (Other, inte Python)
- Titel-gate — inga keyword-träffar i brödtext
- AI-slice tre riksmöten — freeze, hash, locator-KPI, acklamation = partiröst okänd

## Inte klart

- Fylld historik 2023/24 och 2024/25 (titel-gate nollträff i frysen)
- Registrerade voteringar i UI (TU8 = acklamation)
- Anföranden i publik kedja

## Inte

- Ranking, simulator, fler topics, ny frontend

Källa L1: Sveriges riksdag. Kod: Apache/MIT enligt repo.
